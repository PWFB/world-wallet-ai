# Deploy a World Wallet AI contract from Termux

This flow is intended for Android Termux. It compiles the exact Solidity file generated by World Wallet AI, deploys it with a locally supplied EVM key, waits for a confirmation, and writes a JSON deployment manifest that can be imported back into the app.

## 1. Generate the contract in World Wallet AI

1. Open **Contract Generator**.
2. Enter the token name, symbol, supply, and decimals.
3. Select **Validate & generate**, then **Download .sol**.
4. Keep the contract symbol handy; it is also the Solidity contract name in generated starter contracts.
5. Start with **Sepolia testnet**, not mainnet. Obtain Sepolia test ETH from a trusted faucet.

You can also open [Remix IDE](https://remix.ethereum.org/) from the Contract Generator, paste the copied Solidity source into a new `.sol` file, compile with a compatible Solidity 0.8.x compiler, and deploy using Remix's **Injected Provider** with your browser wallet. Remix and Termux are alternative deployment paths; neither needs your World Wallet AI login credentials.

## 2. Install the Termux tools

Open Termux and run:

```sh
pkg update -y
pkg install -y nodejs-lts git
termux-setup-storage
mkdir -p ~/world-wallet-contracts
cd ~/world-wallet-contracts
npm init -y
npm install ethers@^6 solc@^0.8
```

Copy the downloaded `.sol` file from Android Downloads into `~/world-wallet-contracts`. In Termux, you can use:

```sh
cp ~/storage/downloads/MTK.sol .
```

Replace `MTK.sol` with the actual filename. Get the deploy helper from the project's GitHub repository:

```sh
curl -fsSL https://raw.githubusercontent.com/PWFB/world-wallet-ai/main/tools/termux-deploy.mjs -o termux-deploy.mjs
```

## 3. Deploy to Sepolia first

The helper accepts only HTTPS RPC URLs and verifies the RPC chain ID before submitting a transaction.

```sh
export NETWORK_NAME=sepolia
export RPC_URL=https://ethereum-sepolia-rpc.publicnode.com
read -rsp "EVM private key (input hidden): " PRIVATE_KEY
echo
export PRIVATE_KEY
node termux-deploy.mjs MTK.sol MTK
unset PRIVATE_KEY
```

Change both occurrences of `MTK` to match your Solidity filename and exact contract name. The private key is read hidden and passed only to the local Termux process; never paste it into ChatGPT, the web app, a public repository, or a source file. Use a dedicated test wallet with no real funds. The script writes `world-wallet-deployment.json` after a confirmed deployment.

Supported `NETWORK_NAME` values:

- `sepolia` — chain ID 11155111; testnet
- `ethereum` — chain ID 1; real ETH and mainnet fees
- `bnb` — chain ID 56; real BNB and network fees

To change networks, set both `NETWORK_NAME` and `RPC_URL` to matching values. The script aborts if the RPC chain ID does not match.

## 4. Import the deployment into the app

After successful deployment, open `world-wallet-deployment.json`. In World Wallet AI, open **Contract Generator** and use **Import Termux deployment JSON**. This saves the contract address, network, transaction hash, deployer, and explorer links to the app's local browser storage and refreshes the contracts list.

Importing a manifest only saves a reference in the app. It does not redeploy the contract, prove source verification, or move tokens. Confirm the address and transaction on the relevant block explorer.

## Safety notes

- Test on Sepolia before considering a production deployment.
- The helper never uploads or stores your private key in World Wallet AI.
- Never commit `.env`, private keys, recovery phrases, or wallet backups.
- Generated starter contracts are examples, not audited financial software. Have the source independently reviewed before handling real assets.
