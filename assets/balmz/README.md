# BALMZ artwork and metadata

- `balmz-logo.svg` is a **draft concept**, not yet approved as final token artwork.
- `project-metadata.json` is an internal project metadata registry, not a production Metaplex metadata payload and not an on-chain metadata URI.
- No canonical website, immutable image URI, or immutable metadata URI has been recorded.

Before publishing token metadata:
1. obtain owner approval for the artwork and exact token description;
2. publish approved artwork and standards-compliant metadata to a durable immutable content URI;
3. independently fetch both URLs and record their content hashes;
4. ensure the metadata uses only verified production chain addresses;
5. do not publish unverified market price, pool, audit or listing claims.
