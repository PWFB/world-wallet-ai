# BALMZ Roadmap

This roadmap is milestone-based. No calendar date is a promise, and a milestone is complete only when its evidence is published.

## Phase 1 — Specification and source readiness

- [x] Record the 31B global production allocation in the EVM contract source and tokenomics documentation.
- [x] Define separate Ethereum, BNB Chain, Solana, and testnet allocations.
- [x] Implement fixed-supply EVM token and immutable Ethereum reserve-vesting source.
- [ ] Implement and review the Solana Mainnet mint with 9 decimals and final authority policy.
- [ ] Complete the full release test matrix on the exact release commit.

## Phase 2 — Controlled production deployment

- [ ] Confirm authorized deployer/custody and exact chain IDs.
- [ ] Deploy Ethereum and BNB contracts through owner-reviewed wallet transactions.
- [ ] Deploy Solana Mainnet mint through its authorized signer.
- [ ] Record deployment transactions, addresses, observed supplies and authority states.
- [ ] Verify all source code and token metadata on the relevant explorers.

## Phase 3 — Public identity and project information

- [ ] Approve the official BALMZ logo and token artwork.
- [ ] Publish canonical metadata JSON and immutable image URL.
- [ ] Publish dedicated BALMZ project website, contact channel, privacy terms and risk disclosure.
- [ ] Publish chain registry, tokenomics, vesting schedule and actual governance status.

## Phase 4 — Security and operational readiness

- [ ] Complete independent third-party audit covering the exact deployed source.
- [ ] Resolve or transparently disclose all findings.
- [ ] Test wallet integration, token transfers, settlement and reconciliation on each production chain.
- [ ] Document incident response, key management and treasury approval controls.

## Phase 5 — Liquidity and market readiness

- [ ] Approve the DEX/pool design and exact treasury funding amount.
- [ ] Fund only after independent wallet and transaction review.
- [ ] Record pool address, reserves, LP ownership/lock state and transaction links.
- [ ] Publish market information only when supported by genuine, observable trading data.

## Phase 6 — Listings and public launch

- [ ] Prepare factual listing applications using verified production addresses.
- [ ] Submit only after the contract, explorer, metadata, website, security and liquidity gates pass.
- [ ] Announce the actual supported networks and risks; do not promise returns or guaranteed prices.

See [BALMZ Release Readiness](../../../../docs/BALMZ-RELEASE-READINESS.md) for the evidence register and current no-go decision.
